# AlphaShop Pro

نسخه حرفه‌ای ربات فروش سرویس.

امکانات:
- فارسی و انگلیسی با تنظیمات مستقل
- عضویت اجباری با دکمه شیشه‌ای
- کیف پول و افزایش موجودی با رسید
- ارسال رسید برای ادمین و تأیید/رد
- پلن‌های ۵/۱۰/۲۰/۴۰ گیگ
- حجم دلخواه با قیمت هر گیگ
- کد تخفیف
- زیرمجموعه‌گیری
- سفارش‌های کاربر
- راهنمای کامل
- پنل مدیریت
- مدیریت قیمت و فعال/غیرفعال کردن پلن
- مدیریت کد تخفیف
- آمار کاربران، فروش و شارژهای در انتظار
- افزایش موجودی دستی توسط ادمین
- ساخت مشتری از طریق API پنل در صورت تنظیم API واقعی

نصب در Termux:
pkg update -y
pkg install python -y
cd ~/AlphaShopPro
python -m pip install -r requirements.txt
cp .env.example .env
nano .env
python -m py_compile bot.py
python bot.py

نکته:
بات باید در کانال REQUIRED_CHANNEL دسترسی لازم برای بررسی اعضا داشته باشد.
برای ساخت خودکار مشتری، PANEL_API_URL و PANEL_API_TOKEN را طبق API رسمی پنل تنظیم کنید.
